# Mapping L.A. neighborhood boundaries

`mapping-la-neighborhoods.json` is the original V6 GeoJSON from the Los Angeles Times Data and Graphics Department, downloaded November 13, 2026. Only JSON whitespace has been removed.

Source: https://github.com/datadesk/mapping-la-data/blob/main/geojson/la-county-neighborhoods-v6.geojson

Methodology: https://maps.latimes.com/about/

The original MIT license is retained in `mapping-la-LICENSE.txt`. These are editorial neighborhood boundaries, not official Neighborhood Council or municipal jurisdiction boundaries.
